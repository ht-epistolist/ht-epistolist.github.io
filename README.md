# Olena Teslia — Personal Website & Portfolio

Welcome to the personal website and engineering/art portfolio of **Olena Teslia**.

Built with [Astro](https://astro.build/) & [Tailwind CSS](https://tailwindcss.com/).

## 🚀 Features

- **Interactive Landing**: Mood-based entry (`tired` / `playful`).
- **Playful Page**: Custom animated stickman excavation scene with dynamic SVG and CSS animations.
- **Portfolio**: Engineering research (Columbia Stellarator eXperiment / CUTE Tokamak, hackathons, robotics) and visual arts (photography, drawings, graphic design, CAD).
- **Career & Timeline**: Interactive timeline, research statement, artist statement, and CV download.
- **Surveys & Feedback**: Interactive voting polls and contact form.
- **Automated Deployments**: GitHub Actions workflow builds and deploys directly to GitHub Pages.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
